# 📊 Proyecto Módulo 6 - Machine Learning

## 🧾 Descripción
Este proyecto tiene como objetivo predecir el monto total de compra de clientes en un contexto de comercio electrónico, utilizando técnicas de aprendizaje supervisado.

---

## 🎯 Objetivo
Desarrollar modelos que permitan predecir el gasto de clientes a partir de sus características.

---

## 🤖 Modelos utilizados
- Regresión Lineal
- KNN
- KNN optimizado
- Gradient Boosting

---

## 📊 Resultados
Los modelos presentan bajo poder predictivo (R² cercano a 0), evidenciando baja relación entre variables.

Se selecciona regresión lineal por simplicidad y desempeño comparable.

---

## 🧠 Conclusión
Los resultados muestran que las variables disponibles no permiten explicar adecuadamente el comportamiento de compra.
